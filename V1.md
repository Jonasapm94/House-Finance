Personal Finance Dashboard (Local Edition)A privacy-first, fully containerized personal finance tracker built for local deployment. Keep your financial data completely offline while enjoying automated categorization and modern data visualization.🎯 OverviewThis system is designed to break dependency on specific bank apps (like Nubank) by using standardized file formats (OFX) to aggregate financial data. To guarantee maximum privacy, this application operates entirely on your local machine via Docker, meaning no financial data ever touches the internet or third-party APIs.🛠️ Tech StackArchitecture
